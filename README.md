# 💰 Sparehacks.no - Smarte Sparetips & Pengehacks

En moderne, responsiv nettside som presenterer hundrevis av praktiske sparetips for nordmenn. Spar tusenvis av kroner årlig uten å ofre livskvalitet.

## 🎯 Funksjoner

- **28+ Sparetips** fordelt på 6 kategorier
- **Kategorisering**: Mat & Dagligvare, Bolig, Reise, Streaming & Abonnement, Bank & Finans
- **Søkefunksjon**: Finn relevante tips raskt
- **Sortering**: Sorter etter popularitet, besparelse eller nyeste
- **Responsiv design**: Fungerer perfekt på mobil, nettbrett og desktop
- **Moderne UI**: Rent, intuitivt design med animasjoner
- **Like-funksjon**: Marker dine favoritt-tips

## 📊 Kategorier

### 🛒 Mat & Dagligvare
Tips om smart mathandel, handlelister, frysing, sesongens grønnsaker og mer.

Dele abonnementer, rotere tjenester, finne gratisalternativer.
**Potensielt spare:** 3,000-8,000 kr/år

### 💰 Bank & Finans
Høyrentekonto, gebyrfrie kort, automatisk sparing, gjeldsnedbetaling.
**Potensielt spare:** 5,000-50,000 kr/år

## 🚀 Kom i gang

Nettsiden er laget med ren HTML, CSS og JavaScript - ingen byggeverktøy nødvendig.

1. Klon repositoryet:
```bash
git clone https://github.com/dittbrukernavn/sparehacks.git
cd sparehacks
```

2. Åpne `index.html` i nettleseren din, eller start en lokal server:
```bash
# Med Python
python -m http.server 8000

# Med Node.js
npx serve

# Deretter besøk http://localhost:8000
```

## 🤝 Bidra

Har du gode sparetips? Bidra gjerne!

1. Fork prosjektet
2. Opprett en branch (`git checkout -b feature/nyttTip`)
3. Legg til ditt tip i `script.js`
4. Commit dine endringer (`git commit -m 'Legger til nytt sparetip'`)
5. Push til branchen (`git push origin feature/nyttTip`)
6. Åpne en Pull Request
